Laws of UX applied in this prototype — lawsofux.com
Hick's Law

Return the best 3–5, not 200 — fewer choices, faster decisions. The core of the product.

Von Restorff Effect

The #1 pick is isolated and opens by default so the best choice is unmissable.

Serial Position Effect

Ranked order places the strongest options where memory holds them.

Miller's Law

Three scores, ≤5 results — chunked to stay inside working memory.

Law of Proximity

Quality · Match · Reliability sit together so they read as one verdict.

Doherty Threshold

A narrated progress sequence keeps the <400ms feel even while ranking runs.

Goal-Gradient Effect

A visible finish line during loading pulls the user through.

Aesthetic-Usability

Animated score reveals and considered type make the tool feel trustworthy.

Fitts's Law

Primary actions (Find, Use this) are large and close to where the eye lands.

Tesler's Law

Inherent complexity lives in the engine; the user only confirms intent.

Postel's Law

Accepts any phrasing of a goal; returns one clean, structured answer.

Peak-End Rule

The "+26" improvement and the copy-success moment end the flow on a high.
